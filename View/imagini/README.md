# Imagini reprezentative pentru clasele de pietre

Cele trei fișiere au fost generate cu instrumentul integrat ImageGen pentru
acest proiect. Sunt imagini fotorealiste sintetice, nu fotografii ale unor
specimene măsurate. Aceeași imagine este folosită pentru toate obiectele aceleiași
clase. Nu se descarcă imagini de pe internet la pornirea aplicației.

| Fișier | Clasa reprezentată |
| --- | --- |
| `pretioasa.png` | PiatraPretioasa — diamant fațetat |
| `magmatica.png` | PiatraMagmatica — eșantion de granit |
| `sedimentara.png` | PiatraSedimentara — eșantion de calcar |

## Prompturi folosite

Pentru fiecare imagine s-a folosit următorul prompt complet, înlocuind doar
`SUBJECT` cu subiectul exact din lista de mai jos:

> Use case: product-mockup. Asset type: local square thumbnail for a student desktop catalog of stones. Primary request: a photorealistic studio macro photograph of SUBJECT. Composition: a single centered specimen fully inside the image with generous margin on a plain neutral charcoal background. Soft diffused light, realistic detailed material, crisp silhouette. No text, no logos, no watermark. No props, no extra stones. This is a representative decorative category image, not scientific identification.

- `pretioasa.png`: `one colorless brilliant cut diamond gemstone with clearly visible facets`
- `magmatica.png`: `one rough granite rock specimen, gray and pale pink speckled quartz feldspar and black mica crystals`
- `sedimentara.png`: `one pale beige limestone rock specimen, a rough weathered chalky surface and subtle sedimentary layers`

Mod: instrumentul integrat ImageGen; fundal opac. Originalele generate au fost
copiate în acest director și păstrate în proiect.
